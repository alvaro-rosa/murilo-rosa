# Como vocês podem ajudar o Murilo

Guia para os professores e a equipe da escola do Murilo: como ele aprende e como
se comunicar com ele em cada momento do dia (sala de aula, refeitório, educação
física, biblioteca, música, artes).

Página única, sem dependências: `index.html`.

Adaptado de *"How Teachers Can Help Me — A Student Advocacy Booklet"*,
School-based Behavioral Health Program, Department of Psychology in Education,
University of Pittsburgh. Tradução livre para o português e adaptação de
linguagem para o contexto do Murilo. O material original permite reprodução para
fins educacionais e não comerciais.
